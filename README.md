# 💜 Purple Aesthetic Calendar
📅 Keep track of your days with a splash of color! ✨

This is a sleek, completely custom purple-themed web calendar built with purely HTML, CSS, and JavaScript. No heavy frameworks, just clean code and beautiful aesthetics to organize your time!

## 🚀 What's New
*   📝 **Interactive To-Do List:** Click on any current or future date to open a daily task manager.
*   📌 **Pinned Notes:** Pin important reminders at the top of your daily list.
*   ⏳ **Time-Travel Proof:** Prevents adding tasks to past dates.
*   🗑️ **Quick Management:** Easily delete all daily tasks or pins with dedicated actions.
*   🐳 **Dockerized:** Hassle-free setup and deployment using Docker Compose.

## 📥 Installation & Setup
Want to grab the code for yourself? Just run these commands in your terminal:

1. 🧬 Clone the repository:
   ```bash
   git clone <ssh URL>
   cd <repository-folder>

2. 🐳 Run with Docker:
    Make sure you have Docker and Docker Compose installed, then build and start the container:
    ```bash

    docker compose up

3. 🌐 Open your browser and navigate to http://localhost:1100 to start organizing your days!
